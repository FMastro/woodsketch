# WoodSketch

WoodSketch is a 3D modeler for people who build things out of wood.

It will feel familiar if you have used SketchUp — the same tools, the same keys, the same way
of drawing. The difference is what the drawing knows. A box in SketchUp is six faces. A board
in WoodSketch is cherry, 3/4" thick, with the grain running along its length, let into a dado
in the side next to it, and it will shrink about a sixteenth of an inch across its width when
the shop dries out in January. All of that comes back out as a cut list, a shopping list,
cutting diagrams and a build sheet per part.

That is the whole idea: **the model is the plan**. You draw the thing once, and the numbers you
need in the shop fall out of it rather than being measured off it by hand.

## What this guide is

Three kinds of page, and it is worth knowing which you are reading.

**The woodworking.** Grain direction, wood movement, reference faces, which joint suits which
situation. None of this is really about WoodSketch — it is why the software asks what it asks.
If you are new to furniture design, start here.

**Getting started.** One project, end to end. Enough to find your way around.

**Reference.** Every tool and its key, every joint, every profile, every material in the
library and how much each species moves. These pages are *generated from the program itself*
by its test suite, so they cannot drift out of date: if a shortcut changes and the page doesn't,
the build fails.

## A note on where it's up to

WoodSketch is pre-1.0 and ships often. Features arrive, and some corners are still rough.
The reference pages are always current because nothing writes them by hand. The guide's prose
is written by a person and so can lag — if a page tells you something the app doesn't do,
that's a bug worth reporting: **Help > Report a Problem**, right in the app. It files the
report for you, no GitHub account needed.
